# Yaswanth Kishore | GitHub Profile Kit

This profile README follows the reference repository's visual structure: a full-width hero, custom section banners, illustrated project panels, a technology constellation, GitHub activity, community recognition and a branded footer.

## Files
- `README.md` — the profile page
- `assets/` — custom SVG artwork and your profile portrait
- `.github/workflows/snake.yml` — generates the contribution snake

## Publish to GitHub
1. Extract this ZIP.
2. Open your local clone of `https://github.com/yaswanth296/yaswanth296`.
3. Copy **everything inside** this folder into the repository root. Keep `assets/` and `.github/` as folders.
4. Replace the existing `README.md` when prompted.
5. Run:

   ```bash
   git add .
   git commit -m "Redesign GitHub profile portfolio"
   git push origin main
   ```

6. On GitHub, open **Actions** and run **Generate contribution snake** once. The workflow publishes the snake to the `output` branch.
